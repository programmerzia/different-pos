# Baseline mockup (the spec)

Snapshot of `tools/mockup` at commit 2078d6c (2026-11-02), the owner's mockup **before** any agent commit
touched it (f2d2ddd and 3e3b602 came later and are NOT the spec). The app must match this version one-to-one:
sidebar groups SELL / CUSTOMERS / CATALOG & STOCK / MONEY / INSIGHTS / ADMIN & SYSTEM, the teal membership
card, the list toolbars, tables and dialogs as built here. Features the owner asked for afterwards (shop name,
variant picker, inline card on the profile, customer statement, SMS, logo) are added on top in this visual
language, never by restyling what is here.

- `index.html`: the built page. Open with file:// to click through.
- `parts/*.py`: the JSX sources (strings) that built it.
- `mock_data.json`: its demo data.
